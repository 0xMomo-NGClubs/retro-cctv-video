# 模型转换与生产执行

本参考规定通用交接，不指定Seedance或其他模型必须使用的API域名。服务地址、认证、模型ID和媒体限制来自用户当前选择的工具/服务及其实际文档。

## 四个职责

1. **通用导演层**：人物、场景、固定机位、动作因果、道具账本、开始/结束状态、声音与交付要求。
2. **提示词转换层**：把同一制作单转成目标模型的语法，绑定实际存在的素材，不改变故事或添加电影运镜。
3. **生产执行层**：使用相应插件、SDK或API完成上传、创建任务、查询和下载，保存任务ID、输入指纹和收费回执。
4. **本地后期层**：接收实际MP4等素材，按实测时长拼接、叠OSD、混音和验收，不依赖生成服务。

## 默认示例：RunningHub / H3

未指定服务时默认参考这条路线。实际采用需要用户提供或已配置可用的API格式图及账户权限。不能把示例变成强制注册，也不能拿本包不存在的公开工作流去提交。

- [H3工作流适配](h3-and-runninghub.md)说明六段提示词、图像槽位和CLI。
- `rh_workflow.py` 与 `rh_client.py` 是可选示例实现。其内的RunningHub官方域名限制仅用于该客户端的凭证路由，不约束通用流程或其他适配器。
- `assets/runninghub.example.json` 需要填入实际节点和工作流信息。私有图、任务记录与媒体不进发布包。

## 可选：Seedance提示词转换

Seedance 2.0/2.5是用户可选的模型方向，需核实执行工具实际提供哪个版本；版本名称本身不证明接口已可用。

如当前环境已有 `sd25-pe`、`seedance-2-5-video-director` 或其他对应版本Skill，可让其读取制作单及必要参考，只产出提示词。遵循所选转换器的输入输出约定；不同时叠加多个互相冲突的转换模板。

本包不复制、不捆绑这些外部Skill，也不自动安装或升级它们。它们缺失时，本包仍可完成导演与后期；需要精确模型语法时使用当前模型文档或用户提供的转换器。

交给转换器的关键信息：

- 固定摄像头的位置、朝向、全景范围，以及允许的切镜边界。
- 每份参考的实际标签、职责、有效区间、保留项和不继承项。
- 事件先后、可见尝试、支撑、动作发力、物体数量和最终状态。
- 无字素材、现场声、对白原文，以及音乐的选择。
- 用户给定的时长与画幅；按所选转换器要求分开提示词和请求参数。

不要把H3的六段标题或 `<Picture N>` 生搬到Seedance，也不要把Seedance某版本的素材数量、时长、标记或编辑能力宣称为所有API通用。只把执行工具真正支持的素材/模式提交进去。

## 接入任意生产工具前

确认工具实际支持：所选模型与操作模式、媒体角色、参数、鉴权、输出和任务生命周期。地址与密钥配置放用户项目的私有环境中，不写入通用Skill、公开示例或README。不要为填写模板猜一个服务地址，也不要把推荐链接用作API地址。

新适配器可以沿用这些最小语义，但请求字段由实际服务决定：

- `prepare`：检查请求与素材，生成输入指纹，离线阶段不收费提交。
- `submit_once`：提交一次，成功后立即保存任务ID。支持幂等键的服务可使用其文档规定的幂等方式。
- `query`：已知任务反复查询；中断后恢复查询，不重新创建。
- `download`：验证结果类型与哈希，不把服务密钥转发给输出CDN。
- `reconcile`：提交超时或响应缺少ID时核对服务历史，确认后绑定；不能盲目重发。

交接给本地后期的是实际可读媒体文件及其时长/帧数。异步任务ID、网页预览、提示词或临时下载URL不等于已经交付成片。

## 当前验证边界

- 通用导演流程与OSD后期来源于实际迭代案例，可复用现有视频做本地处理。
- 配套RunningHub/H3客户端已离线编译真实API图并做防重复提交测试；通用客户端封装未另做付费端到端测试。
- Seedance和其他生产路线目前提供转换/交接指导；本包没有内置其API客户端，不宣称已做这些路线的付费验证。
