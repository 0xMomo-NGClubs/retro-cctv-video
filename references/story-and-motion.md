# 剧情、尺度与运动

选择能在一个可看清的空间、少数关键道具中表达因果的故事。戏剧性来自人物与物体，不靠电影运镜。用户要换内容时保留监控形式，不照搬参考事件。

可用简短状态表：人物起点与目的、触发或失败尝试、物体数量/持有、结束状态。按故事需要分段，不要求所有故事都有四段。

## 可见的思考与情绪

不要只写“很慌，突然想到办法”。远景可读的动作包括：急着上前、伸手或拉动、发现做不到、退下、朝门口张望、寻找地面、目光停在物体、看回目标、走过去。全身动作和停顿优先，台词不能替代尝试过程。

## 握持与发力

两者是不同维度。可按合适的身体条件描述：

`双手包住同一物体 → 重心沉下/后脚承重 → 拉到肩侧或合适高度蓄力 → 蹬地、转腰、带肩、摆臂 → 接触骤停 → 躯干和手臂回弹 → 握着收回`

依重量、人物年龄和目标位置选择合理幅度。不要为防抛掷写成“轻碰”“短促推一下”，也不要靠大音量或抖镜伪装力度。自然运动模糊允许存在，不能因此多出一件道具。

## 道具账本

为关键道具写ID、材质、数量、尺寸、位置、持有者、接触手、允许变化和最终位置。放下需经过“仍在手里 → 接触地面 → 手松开 → 空手离开”，不能变成“已经扔掉但手里还有”。

破损时区分：原物剩余部分、薄片碎屑、致动工具、液体。明确硬度、薄厚、断口、重力落下、撞地停止和流向；薄片不应像泡沫鼓起或无重量滚动。

## 本次制作中验证过的诊断线索

- 人物相对容器过大，会让“需要外援”不成立；先调比例、深度与可达性。
- 没有脚下支撑，人物会像漂浮攀升；拍清实际垫脚。
- 直接拿工具会像预知答案；补失败尝试与寻找。
- 早期完整和后期破损参考无职责地混用，会复制道具或重置状态。
- 过度限制摆幅会变成轻碰；保持握持的同时设计全身发力。
- 为精彩动作追加数字放大，会破坏单机位监控感。

这些是诊断线索，不要求其他故事也出现儿童、容器、工具或救援。
