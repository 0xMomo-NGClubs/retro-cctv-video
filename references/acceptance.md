# 验收与修订

生成前核对：因果可见、尝试有时间；比例/可达性成立；动作有支撑；道具数量/持有/去向明确；发力描述不与保握持矛盾；参考职责明确；收费分支与实际API字段已核实。

段落验收：
- 正常速度看是否像轻碰、无重量、预知答案或拖慢动作。
- 密帧看离手后是否仍在掌中，是否复制、消失、穿透、手间变形。
- 重物放下后手空，下一段物体仍在原处。
- 硬物、薄片、液体可区分，不能泡沫化、滚成圆石或熔化硬壳。
- 人物数量、年龄比例、服装、脚下支撑不跳变。
- 下一段延续实际末态，破口、积水、碎片、站位不重置。
- 镜头不人为推拉/变焦；机位与地点OSD不随动作乱切。

导出验收：
- 看实际成片开头、接缝前后、重要动作与结尾，不只看参考图。
- 数字高度/字距统一，中文可读；文字有低清边缘而非整片糊掉。
- 无旧字重影、字体回退方框、错字、越界或未要求的角标。
- 帧数与尾部长度正确，1fps OSD没有提前截断结尾。
- 全片解码通过；复制音轨时哈希一致。转码不称无损。

先修因果和物体，再看力度/身份，最后做OSD。用户反馈可覆盖顺序。保留通过片段、姿态与种子，只改有证据关联的项；不全片重跑碰运气。

只改字样、色彩、取消变焦时本地重合成，不新增视频生成。

费用分别记录本轮新增、全部试作、直接采用任务全额；部分采用不按秒虚构摊分，未统计的字体/ASR费用不混称总成本。
